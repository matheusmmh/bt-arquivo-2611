## Como abrir

**Windows**
Extraia o zip e abra `Brawl Together.exe` dentro da pasta.

**Mac**
1. Dê dois cliques no zip para extrair. Deixe a pasta `Brawl Together Mac` onde quiser (por exemplo em Aplicativos).
2. Como o jogo não é assinado pela Apple, o macOS bloqueia na primeira vez (diz que está "danificado" ou que é de "desenvolvedor não identificado"). Para liberar, abra o **Terminal**, digite `xattr -cr ` (com um espaço no final), arraste o `Brawl Together.app` para a janela do Terminal e aperte Enter.
3. Se ainda não abrir, rode também no Terminal `codesign --force --deep -s - `, arraste o `Brawl Together.app` de novo e aperte Enter.
4. Abra o `Brawl Together.app`. Na primeira vez o Mac pede permissão para o microfone (chat de voz).

## Jogar online

- Os dois jogadores precisam estar na **mesma versão** (v1.3).
- Deixe a **Steam aberta e logada** antes de abrir o jogo. Windows e Mac jogam juntos.
- Na mesma rede Wi-Fi também dá para usar a opção de rede local, sem Steam.
